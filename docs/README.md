# Documentation

For users:

- `guide.html`: the user guide (tags, the app, commands, sharing, bridges).
- `release-notes/`: what each released component does and what changed.

For developers (the top-level `SPEC.md` and `PROTOCOL.md` are the reference):

- `design/`: design notes per feature, with the reasoning behind the protocol and the code. `PROTOCOL.md` wins where they differ.
- `research/`: measurements and source reading that the code relies on (flood latency, region handling).
- `vectors/`: test vectors shared by the C core, the Python reference, the app and the bridges.
- `nostr-mesh-bridge.md`: the general Nostr over MeshCore framework and the bridge.
